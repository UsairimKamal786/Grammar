# 📝 Daily English Grammar Practice

Welcome to **Daily English Grammar Practice**!  
This repository is designed for learners who want to **improve their English grammar step by step**, day by day.

---

## 📚 What’s Inside

Each day focuses on a specific topic, with:

- Clear explanations  
- Examples  
- Common mistakes  
- Daily practice exercises  


---

## 🏗 How to Use This Repo

1. Pick a day and read the Markdown file.  
2. Try the exercises at the end of each day.  
3. Make your own notes or examples—commits count!  
4. Practice consistently to build strong grammar skills.  

---

## 💡 Tips for Learning

- Read one day per day—don’t rush.  
- Rewrite examples in your own words.  
- Focus on **common mistakes** to avoid repeating them.  
- Use this repo as a **daily practice notebook**.
