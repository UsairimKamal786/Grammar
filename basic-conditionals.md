# Day 13 – Basic Conditionals

Conditionals are sentences that show **“if something happens, then something else happens.”**

---

## 1. Zero Conditional (Facts / Always True)
Used for things that **always happen**.

**Structure:**  
> If + present simple, present simple

**Examples:**  
- If you heat water, it boils.  
- If it rains, the ground gets wet.  
- If you touch fire, it burns.

---

## 2. First Conditional (Future Possibility)
Used for things that **might happen in the future**.

**Structure:**  
> If + present simple, will + verb

**Examples:**  
- If I study, I will pass the test.  
- If it rains, we will stay home.  
- If she calls, I will answer.

---

## 3. Practice Section
Complete these sentences:

1. If I eat too much, __________.  
2. If it rains tomorrow, __________.  
3. If you study every day, __________.  
4. If I go to the park, __________.  
5. If my friend comes, __________.

---

## Notes
- Conditionals = cause and effect  
- Start simple: zero + first conditional  
- Practice by making **your own “if…then…” sentences**  

---

💡 Tip: Writing one conditional sentence every day builds confidence for advanced ones later!
