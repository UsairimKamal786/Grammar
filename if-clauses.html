Day 16 Grammar: Conditionals (If-Clauses) Conditionals are sentences that show cause and effect—“if something happens, then something else will happen.” There are 4 main types: 1. Zero Conditional – Facts & General Truths Structure: If + present simple, present simple Use: For things that are always true. Example: If you heat water, it boils. If I eat too much candy, I get a stomachache. 2. First Conditional – Real Future Possibilities Structure: If + present simple, will + base verb Use: For real things that might happen in the future. Example: If it rains tomorrow, we will stay home. I will help you if you ask. 3. Second Conditional – Unreal / Imaginary Present or Future Structure: If + past simple, would + base verb Use: For things that are unlikely or imaginary. Example: If I had a million dollars, I would buy a spaceship. She would travel more if she were free. 4. Third Conditional – Unreal Past Structure: If + past perfect, would have + past participle Use: For regrets or things that didn’t happen. Example: If I had studied harder, I would have passed the test. They would have joined us if they had known. Quick Tips Use commas after the “if” clause if it comes first: ✅ If it rains, we will cancel the game. ✅ We will cancel the game if it rains. (No comma needed) “Were” is used instead of “was” in second conditional for all subjects: If I were a bird, I would fly. 🕊
